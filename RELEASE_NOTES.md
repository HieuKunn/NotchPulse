# 🚀 NotchPulse v3.8.2

Welcome to NotchPulse **v3.8.2**! This release introduces complete English localization across all menus and HUD elements, convenient Shelf pinning to keep file drop areas open, and a smart hover tab restoration setting.

---

### 🌐 Complete English Localization
- **100% Native English Interface**: Fully localized all Notch HUD panels, Settings tabs, Face ID biometric management, Battery control modes, and Status indicators into clear, native Apple macOS English.
- **Unified Terminology**: Standardized labels across the hardware charge limiter (`Charge Limit`, `Charge to 100%`, `AC Power Mode`, `SMC access ready`), Battery telemetry (`Battery health`, `Power`, `Temperature`, `Power Adapter`), and Face ID security settings.

### 📌 Shelf File Drop Pinning
- **Persistent Shelf Pin Button**: Added a dedicated rounded square pin button in the bottom-right corner of the file drop shelf panel.
- **Hover Persistence**: Clicking the pin locks the Shelf open so moving your cursor outside the Notch area will no longer trigger auto-close. Unpinning instantly returns to standard auto-close behavior.

### 🔄 Hover Tab Restoration Setting
- **Restore Last Tab on Hover**: Added an option under **Settings -> General -> Notch behavior** (`Restore last tab on hover`).
- **Seamless State Memory**: When enabled, hovering back into the Notch immediately restores the tab you were viewing (e.g., CPU/RAM Stats or Battery Monitor) instead of resetting to Home.
