# 🚀 NotchPulse v3.1.5

Welcome to NotchPulse **v3.1.5**! This release focuses on Lock Screen lyrics synchronization and responsive UI improvements.

---

### 🎵 Lock Screen Lyrics Improvements
- **Instant Track Change Reset**: When transitioning to a new song, lyrics immediately reset and scroll back to the beginning (line 0 / top) without waiting for the first lyric line to be sung.
- **Immediate Lyric Highlighting on Expand**: Expanding from the compact media player to full-screen lyrics now immediately centers and highlights the currently active lyric line, removing the delay that previously waited for the next line's timestamp.
- **Synced Lyrics Cleanup**: Old song lyrics are immediately purged when switching tracks to prevent stale subtitles from displaying while new lyrics are loading.
