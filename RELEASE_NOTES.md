## NotchPulse v5.5

### 🍏 Native Settings Experience

- Updated the Settings window shell to better match macOS System Settings.
- Sidebar selection now uses the native macOS row treatment with full-row clicking.
- Search now uses the native sidebar search field.
- Light and Dark Mode surfaces follow the system automatically without a full-window wallpaper blur.
- Switching settings tabs is immediate and avoids unnecessary transition animation.

### ⚡ Performance

- Reduced unnecessary blur and custom rendering in the Settings window for a lighter interface.
