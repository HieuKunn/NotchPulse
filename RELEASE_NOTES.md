# NotchPulse v4.6.3

## 🌐 Landing Page UX & Navigation Enhancements
- **Enlarged Touch/Hover Targets**: Expanded navigation bar link hitboxes with comfortable padding and smooth capsule highlights so clicking anywhere near navigation text reliably navigates to sections.
- **Universal Clean Scrollbar**: Implemented borderless, hidden scrollbar styling across all modern web browsers while maintaining fluid 120Hz smooth scrolling.
- **Dynamic Release Sync**: Auto-updates landing page release badges and direct download links to `v4.6.3`.

## 🔒 Biometric Fluid Unlock & Lock Screen Stability
- **Dynamic Color Morphing**: The Face ID scan features a smooth color transition that starts with electric blue during active scanning and gracefully morphs into Apple's signature biometric emerald green (`#34C759`) as the checkmark draws upon successful authentication.
- **Instant First-Try Recognition**: Added an intelligent camera sensor warmup grace period (1.2s) and balanced mismatch tolerances so Face ID recognizes your face on the very first try without false early cancellations.
- **Lock Screen Rest & Expansion Control**: Keeps notch and floating Dynamic Island collapsed at rest on lock screen, expanding only when hovered, clicked, or displaying inline HUD notifications.

## 🎛️ App Termination Safety
- **Safe Quit Application**: Resolved process termination edge cases to guarantee clean exits when quitting the application from the menu bar.
