# NotchPulse v4.0.0

## 🔒 Re-Engineered Face ID & Lock Screen Unlock
- **Unified Notch & Island Style**: Face ID unlock now visually integrates directly with your active NotchPulse style — displaying cleanly inline whether you use the MacBook Notch or Dynamic Island.
- **Proportional Unlock Animation**: The face scanning animation has been refined and scaled to 80% to fit comfortably inside a compact, streamlined drop-down panel.
- **Lock Screen Hover & Wake**: Seamlessly wake and trigger Face ID scanning by hovering over or clicking the notch on the lock screen, even when the full-screen media player or lyrics are open.
- **System & Terminal Authorization**: Confirm macOS administrator dialogs, installer prompts, and terminal commands (`⌘⌥F`) effortlessly using Face ID with automatic Apple biometrics fallback.
- **Automatic Display Synchronization**: Face ID automatically mirrors whichever display NotchPulse is active on — no manual screen configuration required.

## 📊 Apple-Inspired System Stats
- **Activity Monitor Aesthetic**: Live hardware graphs in the System Monitor notch now feature horizontal reference gridlines, stacked system and user CPU utilization, and smooth memory pressure meters inspired by macOS Activity Monitor.
- **Optimized Monitor Proportions**: Balanced card widths across CPU (1/3), RAM (60% of 2/3), and GPU (40% of 2/3) to give memory and graphics activity optimal screen space.

## 🎛️ Redesigned Settings Experience
- **Dedicated Frosted-Glass Header**: All settings tabs now feature a native macOS frosted glass header bar that pins title text and actions at the top of the window.
- **Clean Scroll Boundary**: Content glides smoothly behind the header bar without text collision or overlapping cards.

## 🐛 Bug Fixes & Refinements
- **Reliable Multi-Display Locking**: Prevented unwanted camera activation when locking the screen (`⌃⌘Q`) on external monitors.
- **Lock Screen Isolation**: Desktop notch and shelf widgets are strictly prevented from opening while the screen is locked.
