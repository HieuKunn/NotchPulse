## NotchPulse v5.7 (Build 478) - Important Release

This release refines the Settings window with native macOS Tahoe header scrolling, keeps macOS Spotlight Search untouched, upgrades Quick Share with real app logos, and ensures reliable drag detection and Launchpad Home organization.

### ✨ Native macOS Settings Header
- **Translucent Scroll-Under Header**: Updated the Settings window titlebar so scrolling content glides cleanly underneath the header with a soft native blur—matching macOS System Settings without harsh dividers or abrupt clipping.

### 🔍 Native Spotlight Search Intact
- **Spotlight Search Protected**: Command + Space and menu bar Spotlight Search remain completely untouched with full suggestions and query filters—only genuine Applications launcher triggers open Launchpad Home.

### 📤 Quick Share: Native App Logos & Square Proportions
- **Real App Logos**: Quick Share services (Mail, Notes, Messages, Reminders, Shortcuts, Freeform, LINE, WPS Office, and Journal) display their crisp native application icons instead of a generic share arrow.
- **Square 1:1 Aspect Ratio**: Fixed stretched AirDrop and service icons in Settings and the Shelf drop zone so every logo keeps a clean square proportion.

### 🧲 Precision Notch & Window Dragging
- **Window Movement Immunity**: Moving or rearranging application windows near the top of your screen will no longer mistakenly trigger closed-notch hover gestures.
- **Accurate File-Drag Open Area**: Scaled the closed-notch drag detection region accurately from the compact closed notch size rather than the expanded Shelf frame.

### 🚀 Launchpad Home: Clean Search & Organization
- **Settings-Matched Search Bar**: Redesigned the search capsule with clean icon spacing so typed text and the cursor never overlap the magnifying glass, staying calm until clicked.
- **Drop Anywhere Out of Folders**: Dragging an app out of an open folder smoothly shifts surrounding icons aside so you can drop it anywhere on the home grid.
- **Rock-Solid Tab Stability**: Releasing an app into a group near the left or right edges stays firmly on the current page.
