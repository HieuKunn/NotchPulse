## NotchPulse v5.7 (Build 471) - Important Release

This release updates NotchPulse v5.7 with improved Launchpad Home navigation, full-screen external display scaling, reliable system Launchpad replacement, native Settings enhancements, and Face ID contrast fixes.

### 🚀 What's New: Launchpad Home
- **Full-Screen Paged App Grid**: Brings back the classic multi-page application grid on macOS with mouse click-and-drag paging, two-finger trackpad swipes, folders, drag-and-drop organization, and instant keyboard search.
- **Full-Screen External Display Scaling**: Automatically adapts icon sizes, grid spacing, and margins proportionally so Launchpad fills large external monitors cleanly edge-to-edge.
- **Seamless System Replacement**: Intercepts built-in and external keyboard Launchpad keys, system shortcuts, Hot Corners, Dock triggers, and four-finger trackpad pinches to open Launchpad Home directly while keeping macOS's native overlay out of the way.
- **Wallpaper Backdrop & Native Search**: Uses your desktop wallpaper with a native blurred backdrop and a clean floating search bar positioned neatly below the notch.
- **Customizable Grid & Quick Access**: Choose your grid columns and rows, icon size, wallpaper background style, and optional Hot Corner trigger in Settings > Productivity > Launchpad, or open anytime via the Notch button, menu bar icon, or Shift+Command+L.

### ✨ Settings Enhancements & Performance
- **Native Sidebar Search**: Switched to macOS's native sidebar search bar with smooth live filtering.
- **Unified Window Appearance**: Synchronized the Settings background with your system Light/Dark appearance.
- **Instant Tab Switching**: Eliminated lag when navigating between Settings tabs by moving heavy background tasks off the main thread.
- **Version & Build Display**: Added the build number next to the version in the Settings header.

### 🐛 Bug Fixes
- **HUD Replacement Stability**: Improved reliability when switching to custom Volume and Brightness notch HUDs without showing overlapping system overlays.
- **Face ID Setup in Light Mode**: Fixed an issue where step titles and password prompts blended into the dark notch background in Light Mode.
- **Consistent Notch Contrast**: Guaranteed the Face ID overlay uses a dark theme so all text and buttons remain clearly visible.
