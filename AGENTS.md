# NotchPulse Agent Instructions & Rules

Always refer to and enforce `.agents/rules/project_guidelines.md` before releasing or committing.

## ⛔️ STRICT RELEASE CONSTRAINT
If the user's prompt does **NOT** contain a direct, explicit command or request regarding releasing (such as "release", "publish", "tag", "release lại", "sửa lỗi build release", etc.), **DO NOT** bump versions or build numbers, **DO NOT** create or push git tags, and **DO NOT** trigger release workflows. Simply make code edits, verify correctness, and commit normally.
